# EarnFlow V1 — Demo

এটি একটি frontend demo. এখনো production-ready নয়।

## চালানো
যেকোনো static hosting-এ ফাইলগুলো upload করলেই homepage দেখা যাবে। ফোনে test করতে ZIP extract করে HTML ফাইল browser-এ খুলতে পারো।

## Production করার জন্য প্রয়োজন
- Secure backend + database
- Real authentication/password hashing
- Admin authentication/roles
- Task verification logic
- Real payment gateway integration
- Withdrawal audit logs
- Anti-fraud/rate limiting
- Terms, Privacy, Refund/Withdrawal policy
- বাস্তব ও যাচাইযোগ্য task/revenue source

Demo login/register localStorage ব্যবহার করে; এটি real user data-এর জন্য নিরাপদ নয়।
